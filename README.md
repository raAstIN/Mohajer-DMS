# Mohajer DMS

سیستم مدیریت پرونده مهاجر یک نرم‌افزار دسکتاپ برای ثبت، نگهداری، جستجو و مدیریت پرونده‌های قراردادی و اداری است. این پروژه با Python و CustomTkinter توسعه داده شده و اطلاعات پرونده‌ها را به صورت محلی در پایگاه داده SQLite ذخیره می‌کند.

![Mohajer DMS Banner](assets/banner.jpg)

## امکانات

- ثبت پرونده با شناسه بایگانی یکتا
- دسته‌بندی پرونده‌ها بر اساس نوع پرونده
- ثبت اطلاعات اصلی پرونده شامل عنوان، موضوع، تاریخ، مدت، وضعیت و مبلغ قرارداد
- ثبت اطلاعات طرفین قرارداد، اطلاعات بانکی و ضمانت‌نامه
- انتخاب تاریخ با تقویم شمسی
- پیوست فایل برای هر پرونده و نگهداری فایل‌ها در پوشه اختصاصی
- مشاهده جزئیات، ویرایش و حذف پرونده
- جستجوی پرونده‌ها بر اساس عنوان، موضوع، تاریخ، نوع پرونده و شناسه بایگانی
- خروجی Excel از نتایج جستجو
- تهیه نسخه پشتیبان خودکار از دیتابیس پس از عملیات ثبت، ویرایش یا حذف
- رابط کاربری فارسی و راست‌چین

## تکنولوژی‌ها

- Python 3.10+
- CustomTkinter
- SQLite
- jdatetime
- Pillow
- openpyxl

## پیش‌نیازها

قبل از اجرا، مطمئن شوید Python نسخه 3.10 یا بالاتر روی سیستم نصب است.

در macOS و Linux:

```bash
python3 --version
```

در Windows:

```bash
python --version
```

## نصب و اجرا

ابتدا پروژه را دریافت کنید:

```bash
git clone https://github.com/raAstIN/Mohajer-DMS.git
cd Mohajer-DMS
```

یک محیط مجازی بسازید و فعال کنید:

```bash
python -m venv .venv
```

در Windows:

```bash
.venv\Scripts\activate
```

در macOS و Linux:

```bash
source .venv/bin/activate
```

وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

برنامه را اجرا کنید:

```bash
python main.py
```

در Windows می‌توانید از فایل زیر هم استفاده کنید:

```bash
Mohajer DMS.bat
```

## ورود به برنامه

برنامه هنگام اجرا ابتدا پنجره ورود را نمایش می‌دهد. کلید پیش‌فرض فعلی:

```text
1234
```

این مقدار در حال حاضر داخل کد تعریف شده است. برای استفاده جدی یا محیط عملیاتی، بهتر است مکانیزم ورود به روش امن‌تر مثل ذخیره hash شده، تنظیمات محیطی یا مدیریت کاربران منتقل شود.

## ساختار پروژه

```text
Mohajer-DMS/
├── main.py                 # نقطه ورود برنامه
├── database.py             # مدیریت دیتابیس، CRUD، جستجو و بکاپ
├── requirements.txt        # وابستگی‌های Python
├── Mohajer DMS.bat         # اجرای سریع در Windows
├── assets/
│   ├── banner.jpg          # بنر پروژه
│   └── icons/              # آیکن‌ها و لوگوها
├── fonts/                  # فونت‌های Vazirmatn
├── files/                  # داده‌های runtime برنامه
│   ├── backup/             # نسخه‌های پشتیبان دیتابیس
│   └── uploads/            # فایل‌های پیوست پرونده‌ها
└── ui/
    ├── add_record.py       # فرم ثبت و ویرایش پرونده
    ├── details_window.py   # نمایش جزئیات پرونده
    ├── login_window.py     # پنجره ورود
    ├── main_window.py      # پنجره اصلی
    ├── reports_window.py   # گزارش‌گیری بر اساس بازه تاریخ
    └── search_records.py   # جستجو و خروجی Excel
```

## داده‌ها و فایل‌های محلی

برنامه در اولین اجرا پوشه‌ها و فایل‌های مورد نیاز را به صورت خودکار ایجاد می‌کند.

- دیتابیس اصلی در `files/cases.db` ساخته می‌شود.
- فایل‌های پیوست هر پرونده در `files/uploads/` ذخیره می‌شوند.
- بکاپ‌های خودکار دیتابیس در `files/backup/` قرار می‌گیرند.

این فایل‌ها داده‌های محلی برنامه هستند و در Git ذخیره نمی‌شوند.

## خروجی گرفتن

در بخش جستجو، پس از نمایش نتایج می‌توانید از داده‌ها خروجی Excel با فرمت `.xlsx` بگیرید. خروجی شامل ستون‌های اصلی پرونده مانند شناسه، عنوان، موضوع، تاریخ، نوع پرونده، مدت و مبلغ قرارداد است.

## نکات توسعه

- فایل‌های تولیدی مانند `__pycache__`، دیتابیس محلی، بکاپ‌ها و پیوست‌ها توسط `.gitignore` نادیده گرفته می‌شوند.
- برای اضافه کردن وابستگی جدید، آن را در `requirements.txt` ثبت کنید.
- قبل از تغییرات دیتابیس، سازگاری با migration ساده موجود در `database.py` را بررسی کنید.
- مسیرهای داده نسبت به ریشه پروژه محاسبه می‌شوند؛ اجرای برنامه از `main.py` توصیه می‌شود.
